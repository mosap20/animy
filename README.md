# Animy

Projet de démarrage React et Vite. La version actuelle contient l’écran de démonstration de Vite avec un compteur React.

## Démarrage

Avec Node.js 22 ou supérieur et npm, exécutez ces commandes à la racine du dépôt.

```sh
npm ci
npm run dev
```

Ouvrez l’URL indiquée par Vite. `npm run build` génère les fichiers dans `dist/`, `npm run preview` permet de les prévisualiser et `npm run lint` lance ESLint.

Le compteur et l’écran se trouvent dans [src/App.jsx](src/App.jsx). [src/main.jsx](src/main.jsx) monte l’application dans le navigateur.
